# Writing

These rules apply to every string a user reads: labels, menus, empty states, errors, toasts and help text. Write short sentences. Use the active voice. Say one thing in each sentence.

## Use sentence case

Capitalize the first word and proper nouns only. This applies to buttons, menu items, titles and headings.

| Do | Do not |
|---|---|
| New document | New Document |
| Move to folder | Move To Folder |

## Start a button with a verb

A button says what happens when the user presses it. Use the verb and the object. Do not use "OK" or "Yes" when a verb can say more.

| Do | Do not |
|---|---|
| Delete task | OK |
| Save changes | Done |
| Invite people | Invitations |

## Tell the user what to do next in an empty state

An empty state has one short line that names what is missing. A second line or a button tells the user how to add it. A filtered list that is empty tells the user how to clear the filter.

| Do | Do not |
|---|---|
| No tasks yet. Create a task to get started. | Nothing to see here! |
| No results. Clear the filter to see all files. | Your search returned zero results. |

## Say what happened and how to fix it in an error

Name the action that failed. Then give the fix, if the user has one. Do not blame the user. Do not show an error code without words.

| Do | Do not |
|---|---|
| Could not save the file. Check your connection and try again. | Error 500 |
| This name is taken. Choose another name. | Invalid input |

## Do not use exclamation marks

The interface speaks in a calm voice. A success toast is short and in the past tense: "Task created".

## Write numbers as numerals

Use "3 files", not "three files". Use the numeral also at the start of a label. Match the noun to the count: "1 change", "2 changes".

## Name things the same way everywhere

Use one word for one thing. The glossary below lists the preferred terms.

| Use | Do not use | Why |
|---|---|---|
| Delete | Remove, trash | "Delete" is final. Use "Remove" only when the item stays elsewhere. |
| Create | Add new, make | One verb for making a new item. |
| Rename | Edit name | Names the exact action. |
| Move to | Transfer, relocate | Short and specific. |
| Sign in | Log in, login | One term for the account flow. |
| Settings | Preferences, options | One home for configuration. |
| People | Users, members | Plain and human. |
| Search | Find, look up | Matches the search field. |
